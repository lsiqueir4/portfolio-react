<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| translation catalog → JSX render | static author-controlled strings (incl. arrays via returnObjects) rendered via t() |
| data.tsx id → t() key interpolation | component builds t() keys from data ids |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03 | Injection (XSS) | projects/about strings + activities arrays rendered via t() | low | accept | All content is static and author-controlled; rendered as plain t() text (React auto-escapes); returnObjects arrays are mapped to text nodes, never dangerouslySetInnerHTML. |
| T-03-05 | Tampering | id-derived t() keys (`projects.${id}.title`) | low | accept | ids are compile-time constants defined in data.tsx (not user input); a missing key surfaces as a visible i18next fallback, not code execution. |
| T-03-04 | Tampering | CONTACTS + project/experience links, images, proper nouns | low | accept | Actions forbid changing links/images/company/institution/tech names; only visible translatable text is keyed (I18N-08). |

No new install surface; no high-severity threat introduced.
</threat_model>
